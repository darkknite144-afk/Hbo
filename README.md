# 🤖 Manhwa Script & Google Flow Prompt Generator Agent

Automated Python Playwright bot that runs on your local browser to generate 10+ hour continuous Manhwa explanation scripts and outputs two separate text files.

## 📄 Output Files Generated

* `output/full_narration_script_ep1.txt` ➔ Complete voiceover script with scene markers.
* `output/google_flow_prompts_ep1.txt` ➔ Line-by-line 16:9 Manhwa image prompts ready for Google Flow (Agent Mode).
